# reproducible build (e.g. a regulated/audited release, or debugging a

# file installs the exact same dependency graph every time, with no resolver
# free choice left for any transitive package. requirements-runtime.txt
# remains the normal, hand-maintained file for everyday builds
# (packaging/build_all.bat uses it, not this one) since it's far easier to
# read and edit; regenerate this lock file from it after any dependency
# change destined for a release.
